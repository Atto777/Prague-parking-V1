Prague Parking V1

Så startar du:
1. Öppna lösningsfilen (.slnx) i Visual Studio.
2. Tryck Ctrl + F5 för att köra programmet.

Programmet kan parkera, flytta, hämta ut och söka efter fordon.
Det har 100 platser. Två motorcyklar kan dela en plats.

Alla parkerade fordon försvinner när programmet avslutas.
